# Парсер новостей «Ведомости»

## Описание проекта

Проект представляет собой программу на языке Python для автоматического поиска и сохранения новостных публикаций с сайта «Ведомости» (https://www.vedomosti.ru/) по заданным ключевым словам.

Найденные новости сохраняются в локальную базу данных SQLite (`news.db`).

## Как работает программа

1. Программа подключается к базе данных SQLite и получает список ключевых слов из таблицы `keywords`.
2. Пользователь вводит ключевое слово, по которому хочет найти новости.
3. Программа отправляет поисковый запрос к API сайта «Ведомости».
4. Из результатов поиска выбираются первые пять публикаций.
5. Для каждой статьи программа получает заголовок, дату публикации, ссылку и текст.
6. Найденные данные сохраняются в таблицу `News`.
7. При повторном запуске программа проверяет ссылки и пропускает статьи, которые уже есть в базе.

Если текст статьи не удалось извлечь, публикация не сохраняется.

## Структура базы данных

База данных `news.db` содержит две таблицы.

**Таблица `keywords`** — хранит ключевые слова для поиска.

**Таблица `News`** — содержит найденные публикации со следующими полями:

- `id` — идентификатор записи;
- `keyword` — ключевое слово;
- `title` — заголовок статьи;
- `date` — дата публикации;
- `url` — ссылка на статью;
- `text` — текст публикации.

## Используемые технологии

- **Python** — язык программирования.
- **Requests** — отправка HTTP-запросов.
- **BeautifulSoup** — извлечение текста из HTML-страниц.
- **SQLite** — хранение новостных публикаций.
- **DB Browser for SQLite** — просмотр и проверка базы данных.
- **GitHub** — совместная работа над проектом.
